# Todoリストアプリ

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-7cg2c5r6)

日々のタスクを効率よく管理できる、シンプルで使いやすいTodoリストアプリです。白を基調とした淡いブルーのアクセントが特徴の、清潔感のあるデザインで、スマートフォンからデスクトップまで快適にご利用いただけます。

## 主な機能

- **タスク管理**: タイトル（必須）・内容・期日・優先度（高・中・低）を設定して、Todoの新規登録・編集・削除ができます
- **完了管理**: チェックボックスで完了／未完了を切り替えられ、完了したタスクは打ち消し線で薄く表示されます
- **フィルタと検索**: 「すべて／未完了／完了」のタブ切り替えと、タイトルでのキーワード検索ができます
- **並び替え**: 期日順・作成順でタスクを並び替えられます
- **期日の強調表示**: 期日が過ぎたタスクは赤色、今日・明日が期日のタスクはオレンジ色で分かりやすく表示されます
- **優先度の色分け**: カードの左端に優先度ごとの色の帯（高=赤・中=オレンジ・低=水色）が表示されます
- **件数表示**: 画面上部に全件数・未完了数・期限切れ数がリアルタイムで表示されます
- **アニメーション**: タスクの追加・削除時のふわっとしたアニメーション、完了時のチェックマークのバウンスアニメーションなど、細かなフィードバックを実装しています
- **削除前確認**: タスク削除前に確認ダイアログが表示され、誤削除を防ぎます
- **編集モーダル**: 編集はモーダルウィンドウで開き、一覧画面に影響を与えません
- **リアルタイム更新**: すべての操作はページの再読み込みなしでその場で反映されます
- **スマホ対応**: スマートフォンでは1列表示になり、新規追加ボタンが右下に固定されます
- **空状態の表示**: タスクが0件のときは、アイコンとメッセージで案内を表示します

## 使用技術

- **React** + **TypeScript** — UIの構築
- **Vite** — 高速な開発・ビルド環境
- **Tailwind CSS** — ユーティリティファーストなスタイリング
- **Supabase** — データベース（PostgreSQL）によるデータ永続化
- **lucide-react** — アイコンライブラリ

## データの保存について

タスクデータは Supabase のデータベースに保存されるため、ページを再読み込みしてもデータは保持されます。
